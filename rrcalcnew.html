About & how the score is computed

This tool reads rksys.dat locally in your browser and shows, for each license, the stats used by Retro Rewind’s VS ranking alongside the minimum value each stat would have to reach (if changed in isolation) to hit the next rank threshold.

  • Score = clamp(α·M + β, 0, 100) where M is a weighted mix of normalized metrics: VR (50%), VS win% (30%), 1st-place count (10%), distance travelled (5%), distance while 1st (5%).
  • Normalizations: VR 0–10,000.00 (or 0–1,000,000 in “fancy” VR) → 0–100 (via internal 0–1000 clamp); 1st-place: 0–2500 → 0–100; distance: 0–50000 → 0–100; 1st distance: 0–10000 → 0–100; Win% 0–100 (if no VS races, baseline 45%).
  • Affine mapping uses anchors so that a strong profile maps near 100 and a weak/brand new profile maps near ~10. Ranks are bucketed by the score (12,24,36,48,60,72,84,94,100).
  • Per-stat notes for max rank (with other stats maxed): VR ≈ 655,000 (≈6,550.00 rating); VS Win% ≈ 43%; there is no hard minimum for Times 1st or distance metrics — extremely strong VR and Win% can still reach max rank even with low 1st-place and distance values.
  • Nothing is uploaded; everything is client-side. You can save this file and run it offline.
