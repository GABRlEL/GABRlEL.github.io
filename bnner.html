binner.ban — Wii Save banner.bin Editor

Single-file web app. Works with save-data banners only (WIBN). Channel/disc meta banners (IMD5+U8) and data.bin exports are not supported.
Drag & drop a raw save banner.bin here or use the Open button.

Tip: If you get “missing WIBN signature”, you likely uploaded a channel/disc banner (IMD5+U8) or an SD export data.bin. This tool supports save banner.bin only.

Backup your banner.bin before using this tool. This tool has only been tested on Dolphin.
