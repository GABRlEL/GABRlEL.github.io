About & Format Notes

This is an offline, single-file viewer for rksys.dat. It parses the four RKPD license blocks and shows DWC data, friends, records, cups, unlock flags, and favorite counts (characters, vehicles, courses, stages). No data is ever uploaded; all parsing happens in your browser.

  • Expected file size: 0x2BC000 (2,867,200) bytes, but the viewer will try to parse even if it differs.
  • All multibyte fields are read in big-endian unless noted.
  • Region is read from global RKGD at 0x26B0A (UInt16).
