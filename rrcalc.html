About & how the score is computed

This tool reads rksys.dat locally in your browser and shows, for each license, the stats used by Retro Rewind’s VS ranking alongside the minimum value each stat would have to reach (if changed in isolation) to hit the next rank threshold.

  • Score = clamp(α·M + β, 0, 100) where M is a weighted mix of normalized metrics: VR (60%), VS win% (20%), 1st-place count (10%), distance travelled (5%), distance while 1st (5%).
  • Normalizations: VR 0–30000 → 0–100; 1st-place 0–1500 → 0–100; distance 0–75000 → 0–100; 1st distance 0–20000 → 0–100; win% 0–100.
  • Affine mapping uses anchors so that a strong profile maps near 100 and a weak/brand new profile maps near ~10. Ranks are bucketed by the score (12,24,36,48,60,72,84,94,100).
  • Per-stat lowest possible value for max rank: 26501 VR, Win%: 65%, Times 1st: 450, Distance & 1st Distance: 9500m/9500m or 45000m/0m
  • Nothing is uploaded; everything is client's side. You can save this file and run it offline.
