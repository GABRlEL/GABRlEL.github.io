Editing Notes

  • Make a copy of your save folder before replacing game files.
  • `data_#.sav` and `run_#.sav` are compressed JSON. This editor decompresses them, edits values, then downloads compressed replacements.
  • Collection states commonly use `locked`, `unseen`, and `seen`. This editor also offers `unlocked` for fields that already use it.
  • Numeric fields are kept as numbers. Blank numeric inputs are saved as `0`.
  • `run_#.sav` stores the active run for that profile. The Run tabs expose common fields; use Raw JSON for nested values not shown there.
  • Use the Raw tab for keys that are not shown in grouped views.
